# tommyfi
A simple terminal-based music player written in bash and few python modules,pulls audio from youtube and blocks ads.enjoy your adfree music.

tommyfi isnt any other music players we have now.its built with passion towards open-source software and an attempt to provide flawless music experience.
tommyfi is a minimalist terminal-based music system built purely in bash.it can be run in linux,and android platforms.the audio engine is MPV.

# Features
- hundreds of songs and thousands in future.
- minimal interface to immersify the user experience as a listener.
- personal user history + database logging
- database can be modified to add songs or delete songs according to individual user.
- complete ad-free experience.yes,the audio engine makes sure that ads can be blocked.

# Setup
in linux (debian) or android (termux):
- sudo apt update
- git clone https://github.com/Fenrir-Security-Systems/tommyfi.git
- cd tommyfi
- ./tommyfimusic.sh
